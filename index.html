    Three moves. No windows.

    ZestDrop lives in the system tray and wakes up only when you need it, in the middle of a drag you were already making.

    1. 1

      Start dragging

      Select one or more files on the desktop or in File Explorer and start dragging, as if you were moving them.

    2. 2

      Press a shortcut

      Shift opens formats, Ctrl + Shift opens tools. F8 and F9 work too. Once the wheel is open you can let go of the keys.

    3. 3

      Release on a petal

      Drop on the format or tool you want. The new file appears next to the original, or in a folder you choose, and the original is never overwritten.

    Real tools when you need them

    Tools that need settings open in their own window with a live preview. When a picture or video has many tools, related ones share a window: apply one change, build on the result, undo the last step if you need to, and save once.

    Every job has its own controls

    • Pause and resume. Pause freezes the whole job, including FFmpeg, and stops the clock. Resume carries on exactly where it stopped.
    • Cancel. Stops the job and removes its unfinished files. Your originals are never touched.
    • Hide. Tucks the card away while the job keeps running, and a tray notification tells you when it finishes.
    • Two at a time. Two jobs run in parallel and the rest wait their turn. Long encodes are never cut off.

    Set it up once

    ZestDrop remembers how you like to work, and it can start without a drag at all. Everything here is in the tray menu.

    Presets
    Tool windows reopen with the settings you used last, and you can save named presets. Regions, times and passwords are never stored.
    Flows
    Chain tools with their presets, such as resize, then watermark, then compress. The flow appears in the tool wheel for that kind of file.
    Watched folders
    New files in a folder are processed automatically, with the results in a ZestDrop output folder inside it.
    Save location
    Save next to the original or always in one folder. Recent results lists your latest outputs, and Copy result puts a new file on the clipboard.
    Clipboard and right-click
    Process a copied screenshot or copied files, or right-click files in Explorer and choose Process with ZestDrop (portable ZIP only).
    Start with Windows
    Off unless you switch it on, from the tray menu or the welcome window.

    Your files stay on your PC

    Online converters ask you to upload your photos, contracts and recordings to someone else's server. ZestDrop does all of the work on your own machine.

    • Nothing is uploaded. Every conversion runs locally and works offline.
    • Originals are never overwritten. Outputs get a clear suffix, and duplicates get a number.
    • Everything is included. FFmpeg, Python, 7-Zip and .NET ship inside the download.
    • It stays out of the way. There's no main window to manage. It only starts with Windows or joins Explorer's right-click menu if you switch that on.

    Questions

    Windows says “Windows protected your PC”. Is it safe?

    The portable ZIP isn't code-signed yet, so Windows SmartScreen warns about any new download from an unknown publisher. Click More info and then Run anyway. To check that your download is the official file, compare it with the SHA-256 checksum published on the release page. The full source code is on GitHub.

    The Microsoft Store version is signed by the Store, so it installs without this warning.

    Is it really free?

    Yes. ZestDrop is open source under the MIT License, with no ads, accounts or paid tiers. Bundled components keep their own licenses. For example, FFmpeg is included as a GPLv3 build, and its exact source code is attached to the v0.1.0 release.

    Are my files uploaded anywhere?

    No. Everything is processed on your computer by the engines bundled in the download, and ZestDrop works with no internet connection. Text recognition uses the recogniser built into Windows, so it runs on your PC too.

    Why is the download about 250 MB?

    It includes everything it needs to run: the .NET runtime, a portable Python with its libraries, FFmpeg and 7-Zip. You don't have to install anything else.

    Where do the converted files go?

    Next to the original by default, with a suffix such as photo-converted.jpg or photo-rotated.jpg. If that name is taken, a number is added, and originals are never changed. To keep everything in one place, choose a save folder from the tray menu. Recent results there lists your latest outputs.

    Is the app available in English?

    Yes. Since v0.1.0 the interface is available in English and Simplified Chinese. It starts in your Windows display language; right-click the tray icon and choose Language / 语言 to switch.

    Do I need Microsoft Office?

    Only for layout-exact exports of Word, Excel and PowerPoint files, such as PDF or images. ZestDrop drives your installed Office to do these. Without Office, you can still extract text and table data from modern Office files.

    How do I update or uninstall it?

    From the Microsoft Store, ZestDrop updates itself; uninstall it like any other app, from Start or Settings › Apps.

    With the portable ZIP, quit ZestDrop from its tray menu. To update, extract the new version into a fresh folder; your settings and presets stay in %LOCALAPPDATA%\ZestDrop. Start with Windows follows the new folder the next time you launch it, but the Explorer right-click menu does not, so switch that off and on again.

    To uninstall, first switch off Start with Windows and the right-click menu if you turned them on, then delete the folder. Delete %LOCALAPPDATA%\ZestDrop too to remove settings and logs.
